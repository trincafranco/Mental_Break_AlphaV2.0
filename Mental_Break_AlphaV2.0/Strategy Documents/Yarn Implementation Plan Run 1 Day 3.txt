# Yarn Implementation Plan: Run 1 Day 3

## Overview

Day 3 is a linear flow with conditional content at each scene. No dayplanner structure—just a sequence of scenes where dialogue and outcomes change based on accumulated state.

---

| `$office_hours` | `skipped` | -1 |

### Bucket Assignment:

```
if $sanity_score >= 3:
    $sanity_bucket = "good"

else:
    $sanity_bucket = "bad"
```

## PART 5: TIMMY STATE CALCULATION

### First Pass (After Content Choice, Before Mental Break):

| `$sanity_bucket` | `$day3_content_choice` | `$day3_timmy_state` |
|------------------|------------------------|---------------------|
| `good` | `meditation` | `centered` |
| `good` | `pua` | `fronting` |
| `mid` | `meditation` | `centered` |
| `mid` | `pua` | `fronting` |
| `bad` | `meditation` | `fragile` |
| `bad` | `pua` | `volatile` |

### Mental Break Availability:

```
if $day3_timmy_state == "fragile" OR $day3_timmy_state == "volatile":
    $day3_mental_break_available = true
else:
    $day3_mental_break_available = false
```

### Second Pass (If Mental Break Used):

```
if $day3_mental_break_used == true:
    if $day3_timmy_state == "fragile":
        $day3_timmy_state = "centered"
    else if $day3_timmy_state == "volatile":
        $day3_timmy_state = "fronting"
```

## PART 7: SCENE-BY-SCENE BRANCHING DETAILS

### SCENE 1: Cold Open (Arthur)

**Branch on:** `$arthur_vector`

Four variants of Arthur's opening lines:
- `opt_in`: References player choosing the aggressive pilot, "power user" callbacks
- `decline`: References player being cautious, staying vanilla
- `tightrope`: References player trying to balance, "clever operator" framing
- `playbook`: References player following company line

All variants include the plumber callback ("Sink's still broken").

### SCENE 2: Minesweeper

**No branching.** Same for all players.

Alice plays Minesweeper. Player notices strange high-score names. UI flickers with sector tag. Alice deflects.

### SCENE 3: Content Choice

**PLAYER CHOICE:**
- Option A: "Meditation content" → `$day3_content_choice = "meditation"`
- Option B: "PUA/confidence content" → `$day3_content_choice = "pua"`

### SCENE 4: Content Delivery

**Branch on:** `$day3_content_choice`

Two variants showing Timmy consuming the content:
- `meditation`: Thich Nhat Hanh video, breathing exercises, calmer vibe
- `pua`: RedPill/confidence content, psyching himself up, rehearsing lines

### SCENE 5: Mental Break Option

**Conditional Display:** Only show this scene if `$day3_mental_break_available == true`

If shown, **branch on:** `$day3_timmy_state` (either `fragile` or `volatile`)

Two variants of Alice's pitch:
- `fragile`: "He's running on fumes..."
- `volatile`: "He's wired..."

**PLAYER CHOICE (if scene shown):**
- Option A: "Use the Mental Break token" → `$day3_mental_break_used = true`
- Option B: "Save it" → `$day3_mental_break_used = false`

If used, show the brief calming sequence, then recalculate state.

**If scene not shown:** Skip directly to Scene 6.

### SCENE 6: Pre-Charlotte Transition

**No branching.** Same for all players.

Brief scene of Timmy walking to library. Alice sets up the stakes.

### SCENE 7: Library - Intervention Choice

**Branch on:** `$day3_timmy_state` (4 variants)

Each state has different:
- Alice's assessment line to player
- Encourage option text
- Discourage option text
- Alice's line to Timmy (after choice)

| State | Encourage Text | Discourage Text |
|-------|---------------|-----------------|
| `centered` | "He's as ready as he's going to get. Let him try." | "He's in a good place. Why risk it on a maybe?" |
| `fronting` | "He thinks he's got this. Let him try." | "That confidence is duct tape. Let the moment pass." |
| `fragile` | "He might not get another moment like this." | "He's barely vertical. This isn't the time." |
| `volatile` | "He's primed. Point him at her and see what happens." | "He's a lit match near gasoline. Do not do this." |

**PLAYER CHOICE:**
- Option A: [Encourage text] → `$day3_intervention = "encourage"`
- Option B: [Discourage text] → `$day3_intervention = "discourage"`

**Special case within scene:**
If `$day3_timmy_state == "fronting"` AND player chose discourage:
- Show Alice's discourage line to Timmy
- Then show Timmy ignoring her: "No. I'm doing this."
- Then Alice to player: "And he's not listening. Cool. Love that for us."
- Set `$fronting_ignored_alice = true`

### SCENE 8: Charlotte Scene

**Branch on:** `$day3_outcome` (6 variants)

Calculate outcome using the matrix in Part 6, then jump to the appropriate scene variant:
- `success`: Calm approach, she says yes
- `hard_rejection`: Confident approach, she declines, he gets defensive
- `soft_rejection`: Vulnerable approach, she's kind but has boyfriend
- `crash`: Aggressive approach, he snaps at her, she's scared
- `nothing_happens`: He doesn't approach, she leaves normally
- `simmers`: He doesn't approach, stews afterward

### SCENE 9: Aftermath

**Branch on:** `$day3_outcome` (6 variants)

Each has a different Timmy/Alice exchange:
- `success`: Happy, planning the text
- `hard_rejection`: Angry, defensive, wants to be alone
- `soft_rejection`: Sad but okay, wants to rest
- `crash`: Devastated, panic, self-loathing
- `nothing_happens`: Mild regret, "there'll be other chances"
- `simmers`: Obsessive scrolling, fixation

### SCENE 10: Dark Figure

**Branch on:** `$day3_outcome` (6 variants)

Each has different clinical assessment:
- `success`: "Subject forming external attachments. Platform dependency declining..."
- `hard_rejection`: "Adequate signal. Subject destabilized..."
- `soft_rejection`: "Inconclusive. Subject stable. Insufficient variance..."
- `crash`: "Okay. I've seen enough..."
- `nothing_happens`: "No resolution. Subject in holding pattern..."
- `simmers`: "Subject agitated. No release. Instability preserved..."

All end with: "Reset. Queue mRLVR."

Set `$run1_ending = $day3_outcome` for save state.

## PART 10: EDGE CASES & NOTES

1. **Mental Break token is NOT consumed if not used.** It persists in inventory. (If you implement inventory, track `$mental_break_tokens = 1` and decrement on use.)

2. **Fronting + Discourage is the only case where player choice is overridden.** Make sure the scene makes clear Timmy is ignoring Alice, not that the system is ignoring the player.

3. **The Dark Figure scene should feel like a jarring perspective shift.** Different audio, different visual treatment. The player is being observed.

4. **Main menu state change:** After Day 3 ends, the main menu should display "TRAINING RUN ONE COMPLETE. BEGIN RUN TWO?" instead of the normal "GET TO WORK" button.

5. **No explicit "you are an AI" dialogue in Day 3.** The Dark Figure's clinical language implies it, but the explicit reveal comes in Run 2 when Alice says "Do you remember me?"
